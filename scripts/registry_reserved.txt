# registry_reserved.txt — diagnostic codes intentionally declared-but-unimplemented.
#
# scripts/registry_check.zig treats a DECLARED code with no emit site as DEAD (a lie:
# the enum claims the compiler catches something it doesn't). If a code is reserved on
# purpose — planned semantics not yet wired — list it here (one code per line) to tell
# the watcher "known gap, don't fire." A `#` line is a comment and does NOT suppress.
#
# Listing a code here is a DECISION, not a default. Empty file = every dead code fires.
#
# The 2026-06-07 triage queue is DRAINED (2026-07-26). Each code below was dispositioned
# from the `confirm` battery plus a grep for the SHAPE of the missing detector — never
# for the code's own name, which proves nothing. Proving RESERVED means proving a
# negative, so each rationale names what would have to exist and does not.
#
# KORU031 was WIRED (point-free choke type-aware claim, 220_025) and is not listed.
# KORU082 was RETIRED, not reserved: a byte-identical twin of TYPE003, which is emitted
# at shape_analyzer.zig and type_inference.zig. A redundant declaration is a consolidation
# target, never future semantics — so it was deleted from the enum rather than suppressed
# here.
