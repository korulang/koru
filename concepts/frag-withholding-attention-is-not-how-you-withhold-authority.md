# Withholding attention is not how you withhold authority (belief)

The morning feedback run had one rule about strangers: notes submitted by website
visitors were to be neither acted on **nor triaged**. Read nothing, report
nothing, a count line at most. The reasoning was sound and I would have written it
myself — an unattended agent that takes instruction from anonymous input is a
compiler steered by whoever fills in a form.

The rule bought the protection it was after. It also spent something nobody
priced: every fact a stranger had already found.

## The conflation

Two different things can be denied to a source, and the old rule spent one to buy
the other:

- **Authority** — the right to *settle* something: to establish that a defect is
  real, to license a commit, to outrank a maintainer's instruction.
- **Attention** — the right to be *read*.

Denying authority was the actual requirement. Denying attention was the
implementation, and it is a strictly worse instrument, because it discards the
part of a note that never depended on its author in the first place. A stranger's
*opinion* that something is broken carries exactly the weight of its author —
which is none. A stranger's *reproduction steps*, run through the toolchain by the
agent, produce a fact, and a fact does not inherit the standing of whoever pointed
at it.

## The rule

**Read everything; let almost nothing move the code.** A source with no standing
is still permitted to be informative, and the honest handling of it is not silence
but a weighed report: read it, try to reproduce it, rank how much it matters, say
why, hand it up already judged. What it may never earn on its own authority is a
fix, a pinned test, a commit, or precedence over a ratified instruction.

The asymmetry that makes this safe, stated plainly: **reproducing a claim is
evidence, not permission.** Confirming that a stranger was right raises how much
the claim matters; it does not promote the stranger. The old charter had no way to
say that sentence, and so it reached for silence instead.

## What this costs, honestly

Triage is not free. Reading and reproducing every public note spends unattended
agent time on input that is mostly duplicates, misunderstandings, and "it worked"
reports. The old rule's real defence was **economic, not epistemic** — and that
defence is untested rather than refuted.

## Open

- **The falsifier.** If a long run of mornings never once produces a public note
  the human promotes, then the separation bought nothing and silence was the
  correct instrument after all. Nothing measures this today: the digest reports a
  salience call, but nothing tracks how many high calls were ever acted on. Until
  that exists, this belief is asserted, not earned.
- **Ranking has no closer behind it.** A reproduction can be checked; a salience
  call is the agent's judgment alone, which makes it the corruptible half of the
  design and the obvious place for flattery to enter.
- Related: [[frag-agreement-between-derived-sources-is-not-corroboration]] — several
  visitors reporting the same thing is corroboration only if they arrived at it
  independently. A playground that hands every visitor the same starter program
  makes that assumption unsafe by construction, which is exactly the shape the
  first batch arrived in.
